# First-slice permissions use Channel Roles

The first product slice uses four Channel-scoped roles: Owner, Admin, Contributor, and Viewer. Channel Types map their actions to these roles. Contributors perform normal record work—including editing or deleting any Table Record regardless of creator—but cannot manage membership, permissions, schemas, integrations, ownership, or Channel deletion. Per-record and per-field access rules are deferred to avoid making ordinary collaboration depend on hidden ownership policy.

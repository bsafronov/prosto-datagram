# AI Agent never receives stored values

The AI Agent prepares queries and orchestrates typed Datagram tools without receiving stored or derived values from any Store. Tools execute queries, filters, aggregations, mutations, presentations, and Chart construction under normal permissions and exchange opaque Result Handles where composition is required. Human-facing values flow directly from tools to host-rendered Data Views. The Agent knows schemas and tool contracts, not storage mechanics or query results, and therefore cannot narrate conclusions based on those values. Values a person deliberately writes in a prompt remain ordinary model input and are outside this Store boundary. This zero-data rule prevents tool retrieval from turning model context into an implicit data plane.

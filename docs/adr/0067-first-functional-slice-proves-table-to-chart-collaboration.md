# First functional slice proves Table-to-Chart collaboration

The first functional slice bundles Channel core, universal Discussion, Table, Dictionary, and Chart behavior. Through CLI and prompt, a person creates and shares a typed Table Channel, another person changes a Record and emits realtime Activity, and the first person creates a live Chart Channel from permission-checked aggregation. Equivalent Operations and results must be observable across CLI, MCP, and agent origins. Conversation specialization and Workflow execution follow this slice.

# Agent Runtimes share one zero-data tool contract

Datagram separates Agent Runtime concerns from the Datagram agent tool contract. An API-backed runtime supports hosted and background execution with explicitly configured provider credentials. A per-person Codex Runtime supports local interactive execution through the official Codex App Server or SDK and its managed ChatGPT login. Both runtimes call the same permission-checked tools, act with the requesting person's authority, and receive no stored or derived values. Codex owns its credentials and plan limits; Datagram does not copy subscription tokens or treat a ChatGPT plan as a generic model API key. Browser-only clients require the API runtime, an external Codex client connected through Datagram tools, or a future native companion.
